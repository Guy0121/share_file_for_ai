# 橋姫・全32カット制作データ

ZIPは3分割です。3つのファイルを同じフォルダーにダウンロードしてから、ZIP①を展開してください（分割ZIPではなく、それぞれ独立したZIPです）。各ZIPの中身を同じフォルダーへ展開すると、制作データ一式がそろいます。

- `hashihime_scene_assets_01of03.zip` — 01
- `hashihime_scene_assets_02of03.zip` — 02
- `hashihime_scene_assets_03of03.zip` — 03

内容：元PNG、32本のSVGアニメーション、台本対応表、編集・書き出しコード。
音声は含みません。能面のカットは3Dモデルの回転ではなく、画像による寄り引きです。
