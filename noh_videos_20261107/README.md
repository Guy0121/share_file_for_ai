## 他のAIへの引き継ぎ

このフォルダー内の part_01.mp4 〜 part_05.mp4 をすべて取得し、番号順に参照してください。各ファイルは単独再生できます。

## 1本に戻す

このフォルダー内で以下を実行してください。

```bash
ffmpeg -f concat -safe 0 -i concat.txt -c copy -movflags +faststart noh_combined.mp4
```

SHA256SUMS.txt に各ファイルの検証用ハッシュがあります。
